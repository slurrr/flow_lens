# FL-0002 – State Space Definition

## Decision  
The primary visualization is a 2D state space:  
**X = dominance (spot − perp)**, **Y = effectiveness (displacement per unit effort)**.

## Rationale  
This separates *actor* from *outcome*, which is the core structural distinction in market flow. Orthogonal axes prevent conflating strength with success.
